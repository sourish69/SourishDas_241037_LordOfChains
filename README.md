# Restaurant Ordering System (Python Console App)

This is a simple console-based food ordering system where a user can place an order from a restaurant based on cuisine type. The restaurants are generated randomly with categories and coordinates. The system handles order creation, distance calculation, and assigns a delivery agent.

---

## Features

- Randomly generates a list of restaurants with categories (Indian, Chinese, Continental)
- Allows a customer to input their location
- Shows available restaurants by cuisine and calculates distance
- Displays a menu based on selected cuisine
- Takes orders until the user types `STOP`
- Creates an order with a unique ID and calculates cost
- Assigns a delivery agent with a random location
- Displays order status throughout the process
